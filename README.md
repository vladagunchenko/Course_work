# Course_work
# Автоматизована інформаційна система обліку автотоварів (АІС)

Курсовий проєкт з дисципліни «Проєктування автоматизованих інформаційних систем».  
Проєкт є базовим модулем складського обліку з перспективою масштабування у повнофункціональний веб-сервіс (дипломний проєкт).
Виконує студентка 45 групи
Гунченко Владислава

## 📌 Основний функціонал
- Перегляд складських залишків продукції (мастильні матеріали, фільтри, рідини).
- Пошук та фільтрація за артикулом виробника, назвою та категорією.
- Додавання нових товарних позицій.
- Редагування цін та залишків на складі.
- Видалення списаних або некоректних позицій.

## 🛠 Стек технологій
- **База даних:** PostgreSQL
- **Серверна частина:** Node.js, Express.js
- **Клієнтська частина:** HTML5, CSS3 (Bootstrap 5), JavaScript (Fetch API)
- **Інструменти розробки та моделювання:** Visual Studio Code, DBeaver, Figma, PlantUML

## 📂 Структура репозиторію
- `/database` — SQL-скрипти створення схеми даних (`schema.sql`) та заповнення тестовими даними (`seed.sql`).
- `/src` — вихідний код локального веб-сервера та користувацького інтерфейсу.
- `/docs` — документація, графічні макети інтерфейсу та матеріали курсового проєкту.
