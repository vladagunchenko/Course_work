# Вебзастосунок «Автосклад і продаж автотоварів (Mannol)»

Автоматизована інформаційна система (АІС) обліку, каталогізації та продажу автотоварів.  
Курсовий проєкт з дисципліни **«Проєктування автоматизованих інформаційних систем»**.

---

## 📋 Проєкт та мета
Проєкт є повнофункціональним вебзастосунком для автоматизації роботи автоскладу бренду Mannol. Система розроблена як практичний модуль складського обліку з підтримкою рольової моделі (RBAC), безпечною авторизацією через JWT та управлінням життєвим циклом замовлень.

---

## 📌 Основний функціонал системи

### 1. Клієнтський модуль (Каталог та замовлення)
* Перегляд актуальної номенклатури продукції (моторні оливи, фільтри, технічні рідини, автохімія).
* Інтерактивний каталог із підтримкою фільтрації та пошуку товарів.
* Динамічний кошик покупця з можливістю коригування кількості позицій та розрахунком загальної суми.
* Формування та оформлення замовлень покупцями.

### 2. Модуль оператора та адміністратора (Панель управління)
* Захищена аутентифікація персоналу на основі **JWT (JSON Web Tokens)**.
* Розподіл прав доступу (**RBAC** — Role-Based Access Control) для операторів і клієнтів.
* Повний цикл CRUD-операцій над товарними позиціями:
  * Додавання нових товарів через інтерфейсні модальні форми.
  * Редагування цін, описів та актуальних залишків на складі в реальному часі.
  * Видалення або списання застарілих позицій.
* Облік і перегляд статусів замовлень.

## 🛠 Стек технологій
* **База даних:** PostgreSQL
* **Серверна частина (Backend):** Node.js, Express.js (REST API, CORS, JWT аутентифікація)
* **Клієнтська частина (Frontend):** HTML5, CSS3, Bootstrap 5.3, Bootstrap Icons, JavaScript (Fetch API)
* **Інструменти розробки та моделювання:** Visual Studio Code, pgAdmin / DBeaver, PlantUML, Git / GitHub

---

## 📂 Структура репозиторію
* `/database` — SQL-скрипти створення схеми даних, таблиць та наповнення тестовими даними (`init.sql`).
* `/public` — клієнтська частина застосунку (статичні файли HTML, стилі, клієнтські скрипти).
* `/screenshots` — актуальні графічні матеріали демонстрації роботи системи (каталог, кошик, панель оператора, авторизація).
* `server.js` — головна точка входу, REST API маршрути та логіка контролерів на Express.js.
* `db.js` — модуль налаштування та підключення пулу з'єднань із базою даних PostgreSQL.
